Case Study 4: Inventory Management System Using Core Java and OOPS
Problem Statement:

Develop a simple console-based Inventory Management System using Core Java and OOPS concepts. The application should allow users to add items to the inventory, increase the quantity of existing items, remove a specified quantity, and check the available quantity of each item. The system must prevent users from removing more items than are available and automatically remove an item when its quantity becomes zero. It should validate user inputs, display a menu repeatedly until the user selects the Exit option, and store inventory data in memory using Java Collections without requiring permanent file storage.
