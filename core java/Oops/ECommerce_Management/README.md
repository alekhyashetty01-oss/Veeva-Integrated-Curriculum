E Commerce Product module
	
  
  Build a simple realistic e-commerce product module by using core java concepts and OOP principles. To build the system the following are the requirements.

1. Represent customers with their personal information this includes name, email, address, phone no while representing customer personal information follow encapsulation, abstraction so that no private data is accessed directly.
2. The system should able to create a pool of customers data (database) we need to perform addition of customers , deletion of customers, manipulation of customer data and retrieval of customers based on different queries like If a customer name is given then the corresponding customer should be returned if a city name is given corresponding customer data should be returned, if a phone number or email is given corresponding customer record should be returned.
3. Manage a catalog of products here manage means we have to create a list of products where at any time there is a possibility of adding new products deleting products manipulation of product data and whenever customers exploring products in ecommerce platform it should perform following query and retrieval 
i. When a product id is given return the corresponding product details.
ii. When a product name is given return the list of products corresponding to name
iii. When a product name, price is given return products matching those
iv, When a product name, range of price is given return the list of products within the range
v. When a product name, company name is  given return list of products produced by that company.
vi. when a product name, company name price is given return the products matching those.
4. The customer should able to register and login with e-commerce platform whenever the customer needs to explore the products and order the products
5. Handles the orders created by customers it means whenever customer explore products they should be added to basket and once customer confirms an order should be created and stored in database. Now on words the order status can be updated in different intervals by the admin based on the activity like order just created and received, order dispatched, order with courier agent and in transit, order delivered to customer, order returned by customer and received.
6. Whenever order is dispatched and it is courier agent then the customer should able to see the tracking details
7. The payment process can be different types like UPI , debit/credit card, cod.
8. While writing code use principles like abstraction, inheritance, encapsulation, polymorphism 
9. when we create an order and we generate order total it is combination of order amount + shipping charge
10. Once this system is simulated try adding gift card payment option
11. If possible provide an option  for customer to have subscription with e commerce platform that subscription can be monthly , quarterly , half yearly , annually during subscription there is no shipping cost for customer
12. Also try if a customer has multiple order having exceeding threshold value provide discounts
