# India State and City Population Directory System (Interactive Console Project)

An interactive, menu-driven Java project using the Java Collections Framework (`TreeMap`, `Map`, `Scanner`).

## Console Menu Features
1. **Add New State**
2. **Add or Update City Population**
3. **Query 1: City Lookup** (O(1) average lookup)
4. **Query 2: State-Level Aggregation** (City-wise list + Total sum)
5. **Query 3: Global City Search** (Finds which state a city belongs to)
6. **Query 4: Population Threshold Filter** (Filters cities exceeding user-entered count)
7. **Display All Records**
8. **Exit**

## How to Run in IntelliJ IDEA
1. Unzip `IndiaPopulationDirectory-Interactive.zip`.
2. Open IntelliJ IDEA -> **File** -> **Open...** -> select `IndiaPopulationDirectory-Interactive`.
3. Open `src/PopulationDirectorySystem.java`.
4. Click the green **Run** button to launch the console in IntelliJ Run tab.
